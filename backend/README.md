# Price Comparison Engine

A scalable e-commerce price comparison platform that compares product prices across multiple platforms like Amazon, Walmart, and others.

## Tech Stack
- Backend: Golang
- Frontend: (Planned - React)
- Database: (Planned - PostgreSQL)
- Cache: (Planned - Redis)

## Features
- Product search
- Price comparison across platforms
- Price tracking (planned)
- Alerts (planned)

```bash
cd backend
go run cmd/server/main.go
